# Data directory

Only disclosure-reviewed aggregate outputs belong in this directory. The
primary release covers study years 2018–2020. Licensed raw NRD archives and
patient-level extracts must remain outside the repository and are excluded by
`.gitignore` and the validation scripts.

The `processed/` subdirectories contain CSV/JSON summaries used by the final
figures and by the public-only validators. They are not substitutes for the
HCUP source data and cannot be used to identify or link individual records.
