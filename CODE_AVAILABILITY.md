# Code availability

Analysis, preprocessing, validation, and figure-generation code; the phenotype
ontology; prespecified analysis plans; environment specifications; and
disclosure-safe aggregate outputs are publicly available in this repository:

https://github.com/FENG1567/nrd-gallstone-cholangitis-early-cholecystectomy

The version associated with the initial public release is `v1.0.0`:

https://github.com/FENG1567/nrd-gallstone-cholangitis-early-cholecystectomy/releases/tag/v1.0.0

Original software and code are provided under the MIT License. The repository
does not contain patient-level NRD records, raw HCUP archives, record-level
predictions, hospital identifiers, credentials, or other restricted source
materials. Researchers seeking to rerun the licensed-data analysis must obtain
the 2018-2020 NRD files directly from HCUP and comply with the applicable
data-use agreement.
