# Public aggregate results

`data/processed/primary_results.csv` contains the six prespecified v4.7
estimands. `bootstrap_replicate_qc_recorded.csv` stores descriptive quality
records for 500 bootstrap replicates, six estimands, and two strategy regimes;
it is not a patient-level table and does not contain row identifiers.

Amendment 005 adds timing-window, subgroup, and unmeasured-confounding
aggregates. Amendment 006 adds calendar-year and leave-one-year-out sensitivity
aggregates. These files are released only with `DISCLOSURE_GATE.json` marked
`PASS`.
