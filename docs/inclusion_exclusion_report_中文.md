# 纳入与排除规则（公开复现说明）

本研究的分析对象为2018–2020年HCUP Nationwide Readmissions Database中，
符合胆石相关急性胆管炎/胆道感染表型并接受治疗性胆道ERCP的成人住院记录。
时间零点定义为记录的治疗性ERCP操作日。主要比较为：操作日后第1–3天内完成
完整胆囊切除，与截至操作日第3天仍未完成完整胆囊切除的策略克隆。

纳入前由结构性、结局盲的步骤逐项筛选：成人（年龄≥18岁）、严格表型、州内
居民、非择期入院、无恶性梗阻排除、无既往胆囊切除/获得性缺失排除、无妊娠
排除、治疗性ERCP操作日可观察，并且ERCP日、住院天数和NRD链接时间顺序有效。
同一NRD链接记录只保留第一条符合条件的入院，并按照官方年度医院框架校验医院
与NRD分层归属。

结构性门通过后，才允许打开链接出院结局。出院后30天与90天随访采用行政窗口，
并在每个Rao–Wu重抽样复现倾向评分、克隆、删失和IPCW步骤。指数住院死亡作为
时间零点后的结局保留，不作为入组排除条件。

公开GitHub包只包含聚合计数、效应估计、质量记录、图形和代码，不包含患者级行、
直接标识符或可逆的私有链接键。任何小细胞信息均须遵守HCUP披露要求；代码在
缺少授权输入、哈希不一致或公开披露门不通过时停止。
