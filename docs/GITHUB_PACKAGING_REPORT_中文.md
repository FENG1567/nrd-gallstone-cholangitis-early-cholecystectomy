# GitHub复现包整理报告

本目录已整理为可供具有HCUP授权的研究者复现的公开代码包。正式研究年份
固定为2018–2020年；包内没有患者级NRD记录，也没有原始压缩包、SAS/Stata
文件、Parquet患者级导出、服务器凭据或内部工作记录。

已补齐的内容包括：

1. v4.7冻结分析、Amendment 005和Amendment 006的相对路径代码；
2. stage-2加密NRD流式预处理、从授权归档生成冻结分析输入的顺序与命令模板，
   以及官方年度医院框架校验说明；
3. ICD/PCS ontology、变量字典、SAP和详细v4.7技术实施协议；
4. 聚合结果、公开披露门、Figure 1–5 PDF/PNG及当前R绘图脚本；
5. 公共授权/哈希allowlist生成器、聚合验证器、静态安全扫描器和GitHub Actions；
6. 数据可用性、输入Schema、纳排标准、中文文件清单和SHA256总清单。

外部授权用户仍需从HCUP分别取得2018、2019、2020年NRD文件，并在仓库外
建立私有输入目录。allowlist默认生成未批准候选，只有经过显式核对并明确
绑定一次性授权后才可转为可执行版本；代码会在哈希不一致、输入缺失、输出已
存在或披露门失败时停止。

原创软件与代码已选用MIT许可证。公开仓库地址为
https://github.com/FENG1567/nrd-gallstone-cholangitis-early-cholecystectomy，
首个固定发布版为v1.0.0。HCUP授权数据、文档和受限来源材料不受MIT
许可证覆盖，不得通过本仓库再分发。只有Zenodo实际签发DOI后才能补写DOI。
