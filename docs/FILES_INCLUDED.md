# Public file inclusion/exclusion inventory

## Included

- `README.md`, reproducibility and data-access instructions, dependency files,
  citation template, and the unresolved software-licence decision placeholder;
- sanitized Python preprocessing with a licensed-data execution guide, frozen
  v4.7 analysis, Amendment 005/006 runners, public authorization/allowlist
  generator, validators, and tests;
- ontology/configuration and the current public SAP plus the detailed v4.7
  technical protocol;
- disclosure-reviewed aggregate CSV/JSON outputs for the primary analysis and
  Amendments 005/006;
- the final Figure 1–5 PDF/PNG files and the three relative-path R generators;
- the Chinese inclusion/exclusion report and this inventory.

## Excluded deliberately

- all 2018–2020 HCUP NRD raw archives, licensed SAS/Stata files, or derived
  patient-level Parquet tables;
- passwords, tokens, SSH material, server addresses, local workstation paths,
  private authorization receipts, and run logs;
- manuscript DOCX files, cover letters, internal working discussion,
  response drafts, and obsolete candidate versions;
- legacy predictive/2022 source-data CSVs that are not inputs to the current
  2018–2020 staged-intervention Figures 1–5;
- TIFF duplicates and generated temporary figure directories;
- any software licence text before the authors make the legal licence choice.

The final root manifest enumerates every included file using a repository-
relative path and SHA256 digest. It intentionally excludes itself.
