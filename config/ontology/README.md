# Ontology scope

The ontology tables are versioned code lists and variable definitions used to
construct the 2018–2020 cohort. Some source tables retain broader fiscal-year
labels because ICD/PCS code validity was audited across adjacent code-set
releases; this does not indicate that later-year patient records are part of
the present public results. The analysis runners and allowlist generator bind
only the 2018, 2019, and 2020 inputs described in `INPUT_DATA_SCHEMA.md`.
